# 💎 Ограбление

**Пошаговая стелс-головоломка: проведите вора к бриллианту и выходу мимо охранников.**

### ▶️ [Играть](https://mysik-portfolio.vercel.app/heist/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- 6 уровней, каждый проверен решателем (поиск в ширину по состоянию игры)
- Охранники ходят по маршрутам и видят на 3 клетки вперёд
- Видно, куда охрана посмотрит на следующем ходу
- Отмена хода, звёзды за число ходов, близкое к оптимальному
- Управление стрелками, свайпами, тапом по клетке или кнопками

## Стек

JavaScript, BFS-решатель уровней. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/heist.git
cd heist
python3 -m http.server 8000
```
